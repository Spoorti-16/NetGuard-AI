Lab Control (Mininet)

This is the original small 4-host demo (lab_controller.py, port 9000). For the full 80-host real-time network with real hosts, the live diagram, injection panel and scheduler, use Network Map, Injection and Scheduler instead - those run against realnet_controller.py, which uses the same control port (9000), so only run one of the two controllers at a time.

Topology: h1 attacker 10.0.0.1, h2 user 10.0.0.2, h3 web+DNS server 10.0.0.3, h4 monitor 10.0.0.4 (all on switch s1). Attacks run only between these virtual hosts.
